# Portfolio Website

Personal portfolio website built with Astro 5 to showcase frontend engineering work, product thinking, and case studies.

This portfolio is designed to present me as an AI-powered Frontend Engineer who builds clean, scalable, and production-ready web interfaces.

## Overview

This website highlights:

- selected frontend projects
- SaaS-style product case studies
- technical decisions
- architecture and UX thinking
- frontend engineering experience

The main featured case study is:

**AI Content Workspace**  
A modern SaaS-style dashboard for generating, managing, and analyzing AI-powered content.

## Tech Stack

- Astro 5
- TypeScript
- Tailwind CSS
- MDX / Content Collections
- Optional React islands for interactive components if needed
